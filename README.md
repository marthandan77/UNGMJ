# UNG Forecast Machine

A research-first, human-readable multi-horizon forecasting application for UNG.

The project is being built against a locked quantitative specification. It will forecast five horizons—60 minutes, 4 hours, 1 trading day, 2 trading days, and 7 trading days—using calibrated probabilistic models and expected-value-based advice.

Initial data source: Yahoo Finance through `yfinance`.

Status: foundation under construction.
